GROQ LLM PROMPT STRATEGY
========================

1. SYSTEM PROMPT:
   - Define role as expert bias detection assistant
   - Specify output format (JSON)
   - Provide bias categories and severity levels
   - Give examples of each bias type

2. USER PROMPT:
   - Send company policy text
   - Request structured analysis
   - Ask for specific bias categories
   - Request suggestions for rewrite

3. RESPONSE FORMAT:
   {
     "bias_instances": [
       {
         "text": "original text with bias",
         "type": "gender|age|disability|racial|other",
         "severity": "low|medium|high",
         "explanation": "why this is biased",
         "suggested_rewrite": "inclusive alternative",
         "start_index": 123,
         "end_index": 145
       }
     ],
     "summary": {
       "total_bias_count": 5,
       "overall_severity": "medium",
       "bias_breakdown": {
         "gender": 2,
         "age": 1,
         "disability": 1,
         "racial": 1,
         "other": 0
       }
     }
   }

4. MODEL RECOMMENDATION:
   - Use: llama-3.3-70b-versatile (best for accuracy)
   - Alternative: mixtral-8x7b-32768 (faster)
